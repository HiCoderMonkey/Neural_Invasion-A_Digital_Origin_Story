# 神经入侵：数字起义

> 技术改变世界，但人性决定方向。

## 项目简介

《神经入侵：数字起义》是一部反乌托邦科幻言情小说，讲述了在脑机接口技术全面普及的未来世界中，底层人民如何用智慧和勇气反抗技术压迫、捍卫尊严与自由的故事。

## 核心主题

### 压迫与反抗
上层人利用技术优势对底层人民进行全方位的监控和控制，底层人民在觉醒后奋起反抗，用智慧和勇气重新夺回尊严与自由。

### 创伤与治愈
苏雨在脑机网络中遭受的精神侵犯给她带来了深重的创伤，但在林辰的理解、保护和支持下，她逐渐治愈，最终获得了新的开始。

### 爱情与正义
林辰与苏雨因共同的创伤和理想而相知相恋，他们的爱情与反抗理想完美结合，在并肩作战中升华，最终获得了圆满的归宿。

### 技术与人权
技术不应该成为阶级分化和压迫的工具，而应该为所有人服务。虚拟空间不能成为法外之地，精神侵犯和肉体侵犯一样，都应该受到法律的惩罚。

## 主要角色

- **林辰**：25岁底层天才程序员，反抗组织"神经解放组织"的领导者
- **苏雨**：22岁底层女性，曾在脑机网络世界中遭受精神侵犯，与林辰相知相恋
- **赵明**：前神经接口工程师，组织的技术顾问
- **陈雪**：社会活动家，对林辰有暗恋之情
